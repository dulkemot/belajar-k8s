Notifikasi "Update tersedia" ditunda berbulan-bulan? Kebanyakan serangan siber besar (termasuk ransomware WannaCry yang melumpuhkan rumah sakit) mengeksploitasi celah yang sudah ada tambalannya — korban hanya belum update.

Atur sekali, aman selamanya

  • Windows: Settings → Windows Update → Advanced → aktifkan "Receive updates for other Microsoft products" + set Active Hours sesuai jam kerja agar restart tidak mengganggu.
  • HP Android/iPhone: Nyalakan auto-update aplikasi + install update sistem di malam hari (colok charger, konek WiFi).
  • Router & aplikasi kasir: ini yang paling sering dilupakan — catat di kalender tiap awal bulan untuk cek manual.

Takut update merusak?

Kekhawatiran valid untuk sistem kritis (kasir, server). Strateginya: tunda 7 hari (biar orang lain jadi kelinci percobaan), backup dulu, baru update. Untuk HP/laptop pribadi: update langsung, risikonya jauh lebih kecil daripada risikonya tidak update.

Untuk pemilik bisnis

Buat aturan tertulis: semua perangkat operasional wajib update maksimal 14 hari setelah rilis. Satu laptop kasir yang bolong bisa jadi pintu masuk ke seluruh jaringan toko.
