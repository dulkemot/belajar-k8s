Satu printer dipakai 5 orang tapi tiap mau print harus colok-cabut USB? Sharing printer via jaringan beres dalam 10 menit, tanpa beli alat baru.

Cara 1: sharing via Windows (termudah)

Di PC yang tersambung printer: Settings → Bluetooth & devices → Printers → pilih printer → Printer properties → tab Sharing → centang "Share this printer" → beri nama pendek (cth: Kasir-Printer). Di PC lain: tambah printer → "printer yang saya mau tidak terdaftar" → pilih via nama → ketik \\NAMA-PC\Kasir-Printer. Syarat: satu WiFi/LAN + PC induk menyala.

Cara 2: print server USB (±Rp 200 ribu)

Alat kecil yang dicolok ke printer + LAN: printer jadi mandiri di jaringan tanpa PC perantara. Cocok bila PC induk sering mati. Setting via browser sekali, pakai selamanya.

Cara 3: printer WiFi langsung

Printer baru kebanyakan sudah WiFi: sambungkan ke WiFi kantor dari panel printer, install driver di tiap PC via IP printer. Paling rapi untuk jangka panjang.

Masalah umum

  • "Access denied": matikan password-protected sharing (Network and Sharing Center → All Networks) ATAU buat user khusus di PC induk.
  • Hasil bergaris: cleaning head dari driver (Maintenance), bukan bukti tinta habis — jangan langsung beli cartridge.
  • Antrian macet: Services → Print Spooler → Restart. Menyelesaikan 90% kasus "tidak bisa print tiba-tiba".
