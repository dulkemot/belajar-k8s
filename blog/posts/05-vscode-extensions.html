VS Code gratis dan paling populer di dunia. Lima ekstensi ini yang paling terasa dampaknya untuk kerja harian — install semuanya dalam 5 menit.

1. Prettier — perapi kode otomatis

Setiap save, format kode rapi sendiri. Perdebatan soal spasi vs tab berakhir selamanya. Wajib untuk kerja tim.

2. GitLens — siapa mengubah baris ini?

Arahkan kursor ke baris kode, langsung terlihat siapa terakhir mengubah dan kapan. Debugging kode warisan jadi 10x lebih cepat.

3. Error Lens — error tanpa hover

Menampilkan pesan error langsung di barisnya (inline), tidak perlu arahkan mouse. Cocok untuk yang tidak sabaran.

4. Live Server — preview instan

Klik kanan file HTML → Open with Live Server. Setiap save, browser refresh otomatis. Wajib untuk frontend.

5. Thunder Client — Postman di dalam VS Code

Test API tanpa buka aplikasi lain. Ringan, dan request tersimpan sebagai file yang bisa di-commit ke Git.

Tips bonus

Aktifkan Settings Sync (login akun Microsoft/GitHub) agar semua ekstensi dan setting ikut saat ganti laptop. Sekali setting, berlaku selamanya.
