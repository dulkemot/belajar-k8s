Mouse itu lambat. 12 shortcut ini menghemat 5–10 detik tiap aksi — dikali ratusan kali sehari = puluhan menit kembali. Berlaku umum Windows/Linux (Mac: ganti Ctrl→Cmd).

Navigasi kilat

  • Alt+Tab — pindah aplikasi (tahan Alt, ketuk Tab berkali-kali).
  • Win+D — intip desktop / sembunyikan semua.
  • Win+E — buka file explorer langsung.
  • Ctrl+Shift+T — buka kembali tab browser yang tidak sengaja ditutup (penyelamat nyawa).

Editing & file

  • Ctrl+Z / Ctrl+Y — undo/redo di hampir semua aplikasi.
  • Ctrl+Shift+V — paste tanpa format (teks bersih, favorit penulis laporan).
  • F2 — rename file terpilih tanpa klik kanan.
  • Ctrl+S — refleks tiap 5 menit. Data yang belum di-save = data yang belum ada.

Khusus browser

  • Ctrl+L — lompat ke address bar (ketik pencarian langsung).
  • Ctrl+Shift+N / Ctrl+Shift+P — jendela private (untuk login akun kedua / cek harga "bersih").

Cara menghafal: tempel daftar ini di samping monitor, paksa pakai 1 shortcut baru per hari. Seminggu jadi refleks.
